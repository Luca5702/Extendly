### Strict Opaque-Box Invariants
- **Zero Internal Implementation Coupling**: Tests under `/home/antigravity/e2e-tests/android/src/test/kotlin/com/songxi/e2e/` **MUST NEVER** `import com.songxi.app.*` (neither `:core:*`, `:feature:*`, `SongxiAppContainer`, nor `MainActivity` class symbols). - **Dual-Surface Real Execution**: Because `/dev/kvm` is absent and swap is `0B` on this 2-vCPU / `7.8 GiB` RAM VM, E2E verification covers **both** user-facing product surfaces deterministically:
  1. **Standalone Native Android App (`/home/antigravity/songxi-android`)**: Executed on OpenJDK `17.0.21` via Robolectric `4.14.1` (`@GraphicsMode(GraphicsMode.Mode.NATIVE)`, `@Config(sdk = [34])`) + Compose UI Test `1.7.6` (`createEmptyComposeRule()` + `ActivityScenario.launch<android.app.Activity>(intent)`) + APK/Manifest/Roborazzi artifact verification.

- **Strict Zero-`/tmp` Hygiene & Build Serialization**:
  - Every Gradle, JVM, Node, npm, and Chromium invocation inside `run_e2e.sh` exports `TMPDIR`, `TMP`, `TEMP`, `JAVA_TOOL_OPTIONS="-Djava.io.tmpdir=..."`, `npm_config_tmp`, `npm_config_cache`, and Chromium `--user-data-dir` strictly inside `/home/antigravity/.gemini/jetski/scratch/teamwork_tmp/e2e_runner/tmp` (**never `/tmp`**).
